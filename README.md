# Scoop bucket for Deckboy

[Deckboy](https://utopian-academy.github.io/Deckboy/) is free, open-source cue-based media playback and show control for live video: theatre, live events, worship and broadcast.

```powershell
scoop bucket add deckboy https://github.com/Utopian-Academy/scoop-deckboy
scoop install deckboy/deckboy
```

`scoop update deckboy` moves to each new release; the manifest here follows Deckboy's releases automatically. Your show file, settings and logs live in Scoop's persist folder, so they survive updates.

Source, issues and the manual: https://github.com/Utopian-Academy/Deckboy
